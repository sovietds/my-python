学到的东西

变量就是给数据起名字，文字加引号、数字不加

input() 读到的是文字，要算钱得先用 float() 转成数字

print() 输出；= 是赋值，== 才是判断相等

f-string：字符串前加 f，花括号里放变量，拼句子最方便

本量利：利润 = 销量×单价 -（销量×单位变动成本 + 固定费用）
